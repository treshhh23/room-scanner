# Low-Cost 3D Room Scanner
## Specifications
Using the TI MSP-EXP432E401Y as the main microcontroller, a VL53L1X Time-Of-Flight Sensor was used in conjunction with a 28BYJ-48 Stepper motor to perform a 3D visualization of an interior with a relatively small size (~4m). 
Open3D was used to create a point cloud and mesh visualization of the room.

Created for the COMPENG 2DX3 class at McMaster Universty.
